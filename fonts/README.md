# Fonts (self-hosted)

woff2 files as distributed by Google Fonts (latin and latin-ext subsets only), declared with `@font-face` in `index.html`.
All of them are under the SIL Open Font License 1.1 (licence texts next to them, from github.com/google/fonts):

- Archivo, variable: weight 100–900, width 62–125 % (`OFL-archivo.txt`)
- IBM Plex Mono 400 and 500 (`OFL-ibmplexmono.txt`)
- Caveat 500 (`OFL-caveat.txt`)
- Inter, variable: weight 400–800 (`OFL-inter.txt`), and Gochi Hand 400, latin only (`OFL-gochihand.txt`): used only by the KLEX prototype `work/klex/klex-app.html` (FEAT-030)
