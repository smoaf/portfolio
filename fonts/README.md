# Fonts (self-hosted)

woff2 files as distributed by Google Fonts (latin and latin-ext subsets only), declared with `@font-face` in `index.html`.
All three are under the SIL Open Font License 1.1 (licence texts next to them, from github.com/google/fonts):

- Archivo, variable: weight 100–900, width 62–125 % (`OFL-archivo.txt`)
- IBM Plex Mono 400 and 500 (`OFL-ibmplexmono.txt`)
- Caveat 500 (`OFL-caveat.txt`)
